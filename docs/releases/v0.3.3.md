# 大肥鱼 v0.3.3 · 启动与阅读界面

- 启动时播放 5 秒无字动画，去掉应用名、英文标语和图标叠加；支持点击跳过、Esc、减少动态效果，以及播放失败时自动退出。
- 主页继续使用静态壁纸。
- DSH 插件页增加深蓝灰分组面板，提高说明文字、分组标题和开关的辨识度。
- 对话正文使用居中的独立阅读面板，边缘露出壁纸；代码块、行内代码、输入框和标题栏统一为蓝灰色系。
- 提高管理器设置、插件、会话页面和内嵌菜单的文字对比度。
- 保留已有配置、DSH 数据、工作区认证与禁止自动打开浏览器的行为。

Windows x64 安装文件：`DaFeiYu-0.3.3-Setup.exe`。可覆盖安装，或通过软件内更新安装。

验证包括：7 项单元测试、TypeScript 检查、生产构建、960/1180/1920/2560 窗口及缩放、中文草稿保留、认证恢复、真实 DSH 0.2.1-rc.2 插件页和打包程序测试。真实插件说明在最亮壁纸假设下达到至少 4.5:1 对比度。
